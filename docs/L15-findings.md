# L15 の記録 —— メノン完訳と、三度目に主語を失った対照

loop_026。目標は「メノン全 151 節を完訳する」。
メノンはリーダーに載っていて第2層の要旨も 31 頁ぶんあるのに、
三段目だけが空欄で残っていた ——始めたものを終わらせる。

## 1. リーダーの四篇がすべて完訳になった

| 篇 | 節 | 訳 | 配信の重さ |
|---|---|---|---|
| エウテュプロン | 70 | 70 | 142 KB |
| ソクラテスの弁明 | 125 | 125 | 252 KB |
| クリトン | 59 | 59 | 119 KB |
| **メノン** | **151** | **151** | **274 KB** |
| 計 | 405 | **405(100%)** | |

全集に対しては **405 / 8,559 節 = 4.73%**。
メノンは弁明(125 節)より多く、これまでで最も長い翻訳になった。

`/read/men/` は 299 KB(gzip 96 KB)。**分割してあるので他の頁は重くならない。**

## 2. 対照が三度目に主語を失った

L9 で書いた話が、また起きた。

| | 実データの「未訳」 | 対照の在り処 |
|---|---|---|
| L9(裁判三部を完訳) | 消えた | 合成へ移した(T-717) |
| L11(メノンを未訳で載せた) | 戻った | 実データでも撃てる(T-725) |
| **L15(メノンを完訳)** | **また消えた** | **?** |

**そのたびに検査を書き換えるのは無駄である。**
T-725 を「未訳の篇が**あるときだけ**撃つ」形に書き換えた ——
五篇目に未訳の篇が入れば、書き換えなしに勝手に効きはじめる。

ただし「今は未訳が無い」を黙って通すのはよくない。
実データに未訳が無いときは、**合成の対照(T-717)が生きていることを名指しで要求する**
一行を置いた。これが無いと、両方の対照が同時に消えても緑のままになる。

> 状態によって主語を失う検査は、消すのでも書き換え続けるのでもなく、
> **在るときだけ撃ち、無いときは代わりの対照を名指しで要求する**。

## 3. 訳で踏んだ二件

併合の前に走査して、両方とも捕まえた。

**節を一つ落としていた。** 98d に 98e の内容まで詰め込み、151 節のはずが 150 節だった。
節 ID を原文と突き合わせる検算が撃った ——
これが無ければ、リーダーで一節が丸ごと消えたまま出荷していた。

**英単語を二箇所そのまま残していた。** `その術を professed する者たち` のように、
訳しかけて英語が残った。字種の走査が撃った。
[[fleet-cyrillic-leak]] と同じ型だが、こちらはキリル文字ではなく**英単語**である ——
日本語の中のラテン文字は、字形が似ていなくても目では滑る。
