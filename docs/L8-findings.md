# L8 の記録 —— 訳すために読んだら、八ループ分の数が間違っていた

loop_012。目標は「エウテュプロン全 70 節を完訳する(F-12 の二本目)」。
完訳はできたが、**この loop のいちばん大きな成果は翻訳ではない**。

## 1. 訳すために英訳を読んだら、そこに訳者注が混ざっていた

エウテュプロン 4a の英訳は、こう出ていた。

```
because I am prosecutingThe Greek word has much the same meaning as the Latin
prosequor, from which the English prosecute is derived, follow, pursue, and is
at the same time the technical term for prosecute. him.
```

`prosecuting` と `The` がくっついている。Loeb の**訳者注**が地の文に流れこみ、
しかも語の途中に挟まっていた。

上流の TEI はこう書いている。

```xml
because I am prosecuting<note resp="Loeb" anchored="true">The Greek word …</note> him.
```

`<note>` は本文の外にある要素**ではなく**、地の文の内側に置かれている。
節に配って連結すれば、注は訳文として並ぶ。

### 数えたら 12.8% だった

| | |
|---|---|
| 訳者注 | **4,394 件 / 113,710 語** |
| 旧「英訳語数」 | 888,409 語 |
| **注が占めていた割合** | **12.8%** |
| 希語側の訳者注 | 0 件 |

**注は全 36 篇にある。** そして偏っている ——
**国家(Shorey 訳)だけで 2,767 件 88,290 語**、全集の注の **77.6%**。
国家の「英訳」は、旧の数え方では **41.5% が注**だった。

この数は L0 から画面と README の見出しに出ていた。八ループのあいだ誰も落とさなかった。

## 2. なぜ検査を通り抜けたか —— 網が片側にしか無かった

原因は「うっかり」ではない。**検査の配分**である。

| | 希語側 | 英語側 |
|---|---|---|
| 字種検査(G-02) | ある | **無い** |
| トークン列の完全一致(T-004) | ある | **無い** |
| 本文に入れない要素の列挙 | ある(`label` / `head`) | **無い** |

希語は「主たるデータ」で、英訳は「参考」だと扱っていた。
ところが**英訳語数は画面と README の見出しに出ている**。
従たる側の数も読み手には同じ顔で見える。

しかも構造の検査はすべて緑を返す —— XML は妥当で、節の区切りも通り、
希語の語数保存も通る。**注は構造を壊さないからである。**

見つけたのは、和訳のために**人が英訳を読んだとき**だった。

## 3. 直し方 —— 落とすが、落とした量を載せる

`note` を本文から外した。ただし三つの約束を付けた。

1. **外す前に、節の区切りが内側に隠れていないか確かめる。**
   上流実測では注の中の milestone は `unit="para"` の 2 件だけで、
   節の区切りは 1 件も無い。だから丸ごと落としてよい ——
   **その前提が崩れたら黙って節が消える**ので、例外で止める(T-019 が陽性対照)。
2. **外した件数と語数を `index.json` に載せる。**
   黙って消すと「本文語数」が何を数えていないのか読めなくなる(HC-119 と同じ型)。
3. **数を模型で近似せず、実測で閉じる。**(次節)

## 4. 引き算が合わなかった —— そして合わせた

素朴に考えると、注を外せば注の語数だけ減るはずである。合わなかった。

```
旧 888,409 − 新 778,231 = 110,178
注の語数                 = 113,710
                    差   =   3,532
```

差の 3,532 は**注の境目で語がくっついていた分**である。
`prosecutingThe` は旧の数え方では 1 語だった。注を外すと 2 語に戻る。

最初はこれを模型で説明しようとした ——
「前でくっついた注」「後ろでくっついた注」「両側」を数えて引き算する。
**合わなかった**(110,273 対 110,178、95 語ずれた)。
入れ子の深いところで語が終わる場合を数え落としていたのである。

そこで模型をやめ、**正規化器を両方の設定で走らせて突き合わせた**。
これなら模型は要らない。差は 3,532 で、桁まで一致した。

> **合わない引き算を「だいたい合っている」で通さない。**
> 通していたら、3,532 という数は最後まで出てこなかった。

## 5. 一つ見つけたら、同じ棚を全部見る

`note` を直したあと、12b の英訳にまだこう残っていた。

```
there also is reverence.Stasinus, author of the Cypria (Fragm. 20, ed. Kinkel)
```

`<note>` ではなく `<bibl>`(出典表記)だった。
**一つずつ潰すのをやめて、本文に現れる要素を全部数えた。**

その結果、`bibl` は**希語側にもある**とわかった —— 178 件 528 語。
`Hom. Il. 9.363` のようなラテン文字の近代的な出典表記が、
「ギリシャ語本文 559,618 語」に数えられていた。
上流の取り込みが崩れて `ηομ. ιλ. 9.363` とギリシャ文字に化けたものまである。

`bibl` も外した。`quote` の中身(引用された詩句そのもの)は本文なので残す。

### 確定した数(2026-09-03)

| | 旧 | 新 | 外したもの |
|---|---|---|---|
| ギリシャ語本文 | 559,618 | **559,157** | 出典表記 178 件 528 語 |
| 英訳 | 888,409 | **777,817** | 訳者注 4,394 件 113,710 語 + 出典表記 159 件 484 語 |

英訳側の `bibl` は本文の走査では 1,152 件見えるが、うち 993 件は**注の内側**にある。
注を先に外すので、独立に数えられるのは 159 件になる。

## 7. エウテュプロン完訳(本来の目標)

70 節すべてを訳した。裁判三部は劇中の時系列で
エウテュプロン → 弁明 → クリトンなので、頭から埋めたことになる。

| 篇 | 節 | 訳 |

| エウテュプロン | 70 | **70(完訳)** |
| ソクラテスの弁明 | 125 | 0 |
| クリトン | 59 | **59(完訳)** |

| 分母 | 訳済 | 割合 |
|---|---|---|
| リーダーの三篇 | 129 / 254 節 | 50.8% |
| **全集** | **129 / 8,559 節** | **1.51%** |

訳の単位はステファヌス節のままで、**原文の切れ目を動かしていない**。

問いの真ん中で始まるのは、原文がそこで切れているからである。

T-703 には**対照**を足した —— 弁明が「完訳」と出ないことを見る。
これが無いと、全部を complete にする実装でも完訳の検査は通ってしまう。
