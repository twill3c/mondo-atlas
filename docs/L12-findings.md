# L12 の記録 —— 第2層を饗宴 52 頁ぶん進めた

loop_021。目標は「第2層(F-11)の一行要旨を饗宴 52 頁ぶん書く」。

F-11 は SPEC で **must** なのに最も遅れている要求である。
L6 で 53 頁、L11 で 84 頁まで来た。

## 1. 進み具合

| | 頁 | 割合 |
|---|---|---|
| L6(裁判三部) | 53 / 1,752 | 3.0% |
| L11(メノン) | 84 / 1,752 | 4.8% |
| **L12(饗宴)** | **136 / 1,752** | **7.8%** |

饗宴は 52 頁で、いま入っている篇のなかで最も長い。
アポロドロスの語り直しから始まり、六つの演説
(パイドロス・パウサニアス・エリュクシマコス・アリストパネス・アガトン・ソクラテス)、
ディオティマの教え、アルキビアデスの乱入と讃辞、そして夜明けまで。

要旨は**英訳本文を一頁ぶん読んでから書いた**。
52 頁で約 23,600 語を読んだことになる。

## 2. 「半端に埋めない」を検査にした

これまで暗黙に守ってきた規律を、はじめて検査として書いた(T-612)。

**要旨を書いた篇は、その篇の全頁を埋める。**

途中まで書いた篇があると、充填率だけが上がって
「この篇は読める」と誤読される。篇の単位で入れて、入れたら全頁書く。

| 篇 | 頁 |
|---|---|
| エウテュプロン | 15 / 15 |
| ソクラテスの弁明 | 26 / 26 |
| クリトン | 12 / 12 |
| メノン | 31 / 31 |
| 饗宴 | 52 / 52 |

対照も置いた —— **まだ書いていない篇は 0 のまま**であること、
そして「書いた篇と書いていない篇の両方が存在する」こと自体を固定する。
最後の一つが要る。どちらか一方だけになった日に、
上の二つの検査は片方が空回りするからである
(L9 で対照が主語を失った件と同じ型)。

## 3. 字種の混入を一件、併合の前に捕まえた

181 頁の要旨に「生涯を共にしよう」と書くつもりが、
`生涯добも共にしよう` とキリル文字三字が入っていた。

**書いた直後に走査したので、併合の前に消せた。**
`data/curated/` は字種検査の既定除外なので、共有の検査からは見えない ——
だから訳文や要旨を書いたときは自前で走査を回す(HC-121)。

字形が似ているわけでもないのに、目では滑る。
[[fleet-cyrillic-leak]] と同じ型で、このセッションでは三度目である。
