# L16 の記録 —— 五ループ持ち越した宿題を、数えて閉じた

loop_027。目標は「校訂の印(`del` / `add` / `sic` / `gap`)を片づける」。

L8 でこう書いてから、L9・L11・L12・L13・L15 の所見に
**まったく同じ一行**を書き続けていた。

> `del` / `add` / `sic` / `gap`(校訂の印)は本文に残したまま・未計数

残っているだけならまだよい。**未計数のまま残している**のが問題だった ——
「本文語数 559,157 語」の中に何が入っているかを言えない状態が続いていた。

## 1. まず数えた

| 印 | 件数 | 語数 | 意味 |
|---|---|---|---|
| `del` | 402 | 655 | 校訂者が削除を提案した箇所 |
| `add` | 197 | 301 | 校訂者が補った箇所 |
| `sic` | 21 | 33 | 写本のまま |
| `corr` | 2 | 2 | 訂正した読み |
| `gap` | 28 | **0** | 欠落(空要素) |
| **計** | **650** | **991** | 希語本文の **0.18%** |

英訳側にもわずかにある(`del` 2 / `add` 6 / `gap` 3 / `corr` 2 / `supplied` 3)。

## 2. 残す判断が正しいかを、実測で確かめた

`normalize.py` の説明にはこう書いてあった。

> `<del>` と `<add>` は OCT の紙面に現れるので本文に含める。

**これは測っていない理由である。** 紙面に現れるかどうかは私が見たわけではない。
危ないのは二重計上 —— 同じ箇所の二つの読みが両方とも語数に入る場合である。
三つ測った。

| 確かめたこと | 実測 |
|---|---|
| TEI の `<choice>`(対立候補の構造) | **0 件** |
| `sic` と `corr` が対になっているか | **なっていない**。親はどれも本文の要素(`said` / `l` / `q` / `quote`) |
| `del` と `add` が空白なしで隣接するか | **599 件中 1 件**だけ(`add ὂν` の直後に `del αὖ`) |

どれも「あれかこれか」ではなく、**唯一の読みとして本文中に立っている**。
だから二重計上は起きない。残す判断は変えない ——
だが今度は、**変えない理由が測ってある**。

## 3. 外すときと同じ扱いを、残すときにもした

HC-140 で「装置を外すなら、外した量を `index.json` に載せる」と決めた。
その裏返しをやった —— **残すなら、残した量を載せる**。

```
本文に残した校訂の印(希): add 197 件/301 語 / corr 2 件/2 語 /
                          del 402 件/655 語 / gap 28 件/0 語 / sic 21 件/33 語
  → 上の希語 559157 語には、この 991 語が含まれる
```

> 数を出す理由は、外したときも残したときも同じである ——
> **その数が何でできているかを言えなければ、数だけが独り歩きする。**

## 4. 根拠そのものを検査に固定した

T-020 が件数と語数を、T-021 が**残す判断の根拠**を見る。

T-021 は上流に `<choice>` が現れたら落ちる。
そのときは同じ箇所の複数の読みが本文語数に二重で入るので、
扱いを決め直さねばならない —— **黙って通さない**。

判断の根拠を検査にしておくと、前提が崩れた日に気づける。
「この判断はこういう理由で正しい」と書いただけでは、理由が崩れても文章は残る。
