# L4 所見 — 画面③「語の地層」(2026-09-02)

## 1. 屈折語は、語幹では数えられない

ギリシャ語の名詞は格と数で形が変わる。見出し語で数えることはできない。
かといって語幹の前方一致で拾うと、まったく別の語が混ざる。

実測してみると、これは**両方向に壊れる**。

### 拾いすぎ

| 語幹 | 目当ての語 | 一緒に拾ってしまうもの |
|---|---|---|
| `ειδ` | εἶδος(形相)411 件 | **εἰδέναι(知ること)244・εἰδώς 87・εἴδωλον 26** —— 合わせて 631 件 |
| `ψυχ` | ψυχή(魂)1,142 件 | ψυχρόν(冷たい)17・ψύχεσθαι(冷やす) |
| `νομ` | νόμος(法)918 件 | **νομοθέτης 62・νομίζω 41・νομοφύλαξ 28** —— 合わせて 883 件 |
| `αληθ` | ἀλήθεια(真理)244 件 | **形容詞 ἀληθής の一族 1,189 件** |
| `λογ` | λόγος 2,480 件 | λογισμός・λογίζομαι・λογιστική |

語幹 `ειδ` では、**目当ての語より別語のほうが多い**。

### 取りこぼし

語幹 `πολι` は πόλις の斜格 **πόλεως(281 件)・πόλει(391)・πόλεις・πόλεων** を
まったく拾わない。ι で始まらないからである。

**片側だけ直すと、二つの誤りが打ち消し合って総数がそれらしく見える**(HC-127)。

## 2. だから語形の採否台帳を作った

`data/curated/word-ledger.json` に、14 の見出し語それぞれについて

- **採る語形**(アクセントを畳んだ形)を明示的に列挙する
- **表層で落とすもの**を書く —— アクセントを外すと同じになるが別語のもの
- **落とした語群と理由**を書く

### アクセントを畳むと消える区別

| 採る | 落とす | どちらも畳むと |
|---|---|---|
| νόμος(法)158 | **νομός(牧草地)1** | `νομοσ` |
| ἀγαθῶν(善の)146 | **Ἀγάθων(『饗宴』の登場人物)28** | `αγαθων` |
| ἐπιστημῶν(知識の)37 | **ἐπιστήμων(知っている)46** | `επιστημων` |
| εἴδη(形相)123 | **εἰδῇ(οἶδα の接続法)9** | `ειδη` |
| πόλεων(国々の)57 | **πολέων(πολύς の詩形)1** | `πολεων` |
| φύσιν(自然を)357 | **φῦσιν(φύω より)1** | `φυσιν` |

最後の 3 つは 1 件ずつだが、**1 件でも別語は別語**である。
`πολέων` はミノス 320d のヘシオドス引用で「多くの」の意味だった。
`πολεῖ`(クラテュロス 405d・408c)は動詞 πολέω で、πόλει と畳みで衝突する。

## 3. 台帳は両方向で検算する(`etl/audit_words.py`)

1. **書いた語形は実在するか** —— 0 件の形は語形変化表の書き間違い。
   最初に走らせたとき δικαιοσύνη と ἀλήθεια の複数形 5 つが 0 件だった。
   正規の語形だが**プラトンが使っていない**ので台帳から外した
   (検算 1 が意味を持つように、台帳には実在する形だけを置く)。
2. **畳みが別語を巻き込んでいないか** —— 採った形ごとに表層を全部並べる。
3. **取りこぼしていないか** —— 広い語幹で拾える形のうち採らなかったものを全部並べ、
   台帳の `rejected` に書いた群に収まるかを見る。

検算はすべて通っている(exit 0)。

## 5. 「イデア論」の語は ἰδέα ではない

日本語で「イデア論」と呼ばれるが、本文で数えると

- **εἶδος 411 件**
- **ἰδέα 98 件**

**4.2 倍の差**がある。しかも ἰδέα が最も濃いのはティマイオス(0.59)で、
どの篇でも 0.6 を超えない。形相説の語は εἶδος のほうで、
それが最も濃いのは『パルメニデス』—— 形相説そのものが批判にかけられる篇である。

この差は台帳の判断に依存している。語幹 `ιδε` で拾うと **ἰδεῖν(見ること)116 件**が
混ざって ἰδέα が 2 倍以上に見え、`ειδ` で拾うと εἶδος が 2.5 倍に膨らむ。
**どちらも落としてはじめて、この比が言える。**

## 6. 図の作り

- 縦 = 36 篇、横 = 篇を 40 等分した位置、値 = **千語あたりの出現数**。
  篇の長さが 68 倍違うので、素の件数で並べると長い篇が濃く見えるだけの図になる
- 濃さは単一色相の 5 段。**上端は 95 パーセンタイルで切り詰めてある** ——
  一区間の突出で他が全部最下段に潰れるのを避けるため。**切り詰めたことは凡例に書く**
- 段の境目は選んだ語の実データから導く(G-07)。語を切り替えると段も動く
