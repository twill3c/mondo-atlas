# L0 所見 — データの素性(実測 2026-09-02)

すべて `etl/explore/` のスクリプトによる全数走査の結果である。推定値は含まない。

## 1. 規模

| 項目 | 実測 |
|---|---|
| 作品 | 36 篇(希 36 / 英 36、欠けなし) |
| ステファヌス節(`327a`) | **8,559** |
| ステファヌス頁(`327`) | **1,752** |
| ギリシャ語本文語数 | **559,618**(話者記号・見出しを除く) |
| 英訳語数 | 888,409 |
| `<said>` | 14,979 |
| `<label>`(印刷面の話者記号 `ΣΩ.`) | 12,544 |

走査だけの段階では「8,560 節 / 574,506 語」と記録していた。正規化して数え直すと
**節は 8,559**(1 件は `n="imbedded dialogue"` で節ではない)、
**本文語は 559,618**(差の 14,888 語は話者記号と見出し)である。
最初の数はどちらも**数えるものを決める前に数えた値**だった。

## 2. 構造

- 位置の単位は全篇共通で `<milestone unit="section" resp="Stephanus" n="327a"/>`。
  空要素であり、**次の milestone までの本文がその節に属する**。
- `<div subtype="section" n="327">` の `n` は**ステファヌス頁番号**。節(a–e)ではない。
- 『国家』(book 10)と『法律』(book 12)のみ `book > section` の二層。
  section の `n` は篇内で通し(重複 0 件)。巻ごとの振り直しは無い。
- 『書簡集』は `letter` div を持つ。
- 本文中の要素: `q` 1,079 / `l` 318(韻文引用)/ `del` 402 / `add` 197 / `gap` 28 /
  `quote` 266 / `term` 279 / `persName` 428。

## 4. 話者マークアップの正体(**設計を変えた発見**)

### 4.1 `said` は印刷面の話者記号の写しである

**29 / 36 篇で `said` の件数と `label` の件数が厳密に一致する。**
偶然ではなく、Perseus の `<said>` が OCT の印刷された話者記号(`ΣΩ.` `ΚΡ.`)から
機械的に導かれたことを示す。

したがって **OCT が話者記号を印刷しない篇 —— 語り直し型の対話篇 —— では `said` は使えない。**

### 4.2 例外 7 篇の内訳

| 篇 | said | label | 叙述内の発話動詞 |
|---|---|---|---|
| パルメニデス | 1,072 | 0 | 29 |
| エウテュデモス | 610 | 95 | 433 |
| プロタゴラス | 315 | 74 | 282 |
| 国家 | 278 | 0 | **2,136** |
| リュシス | 255 | 0 | 161 |
| 饗宴 | 56 | 6 | 161 |
| カルミデス | 24 | 0 | 215 |

### 4.3 例外篇の `said` は誤っている

実物を開いて確かめた。

- **リュシス**の最初の `<said who="#Σωκράτης">` の中身は
  「ἐπορευόμην μὲν ἐξ Ἀκαδημείας εὐθὺ Λυκείου…(私はアカデメイアからリュケイオンへ歩いていた)」
  —— 発話ではなく**地の文**である。
- **パルメニデス**は 1,072 件すべてが枠の語り手 `#Κέφαλος` に付いており、
  その内部に「φάναι τὸν Σωκράτη(とソクラテスが言った)」を含む。
  つまり**別人の発話が Κέφαλος の発話として数えられている**。

**当初 `said` 密度 70.2 で「最も対話的な篇」の上位に置いたパルメニデスは、数字自体が無意味だった。**
この指標をそのまま画面に出していれば、テストは緑のまま図が嘘をつくところだった。

## 5. 埋め合わせる手がかりは本文の中にある

語り直し型の篇では、話者交替は**叙述内の発話動詞**で標示される。これは
校訂者の付けた印ではなく、**ギリシャ語の文そのもの**である。

| 形 | 意味 | 人称 |
|---|---|---|
| ἦν δʼ ἐγώ | 「と私は言った」 | 1 人称 |
| ἦ δʼ ὅς | 「と彼は言った」 | 3 人称 |
| ἔφη / ἔφην | 「彼は言った」/「私は言った」 | 3 / 1 人称 |
| εἶπον | 「私は言った」 | 1 人称 |

分布は `label` と**きれいに相補的**である。

- 『国家』: `label` 0、発話動詞 **2,106 件**
- 『カルミデス』: `label` 0、発話動詞 208 件
- 上演型の篇(エウテュプロン・クリトン・ゴルギアス・法律ほか)ではこれらがほぼ 0

**『国家』の問答は 278 回ではなく、約 2,000 回起きている。**
`<said>` だけを見ていると、全集で最も長い対話篇が「ほとんど対話していない」ように見える。

> **この節の数は L2 で訂正した(2026-09-02)。** 当初は
> 「`ἦ δʼ ὅς` 181 / `ἔφη` 1,144 / 合計 2,136」と書いていたが、計数が二方向に誤っていた。
> (1) ギリシャ語のアクセントは後続語で鋭→重に変わるので、字面で照合すると
> `ἦ δʼ ὃς` の形を取りこぼす(全集で +17、『国家』で +7)。
> (2) 語境界を置かないと `ἔφη` が `ἔφην` の内側にも当たり、全集で 271 件を過大に数えた。
> 正しい『国家』の内訳は 601 / 188 / 1,064 / 77 / 133 = **2,063**、
> 検出器で数え直した交替は **2,106** である。「約 2,000 回」という主張自体は変わらない。
> 詳細は [L2 所見](L2-findings.md) と HC-127。

## 6. 設計への反映

1. **F-05a**: 発話交替の検出は `said` / `label` を使わず、本文の言語的手がかりで書く。
2. **G-03(循環の禁止)**: 検出器の入力に `said` が現れないことをコードで検査する。
   `label` は検出器を**書き終えたあと**の答え合わせにのみ使う(上演型 29 篇が正解データになる)。
3. **F-05c**: 篇ごとに「上演型 / 語り直し型」と、同定の根拠を画面に出す。

## 7. 正規化して分かった上流の性質(2026-09-02)

正規化器を書いて全 36 篇を通したところ、走査だけでは見えなかった 4 種の例外が出た。
いずれも**黙って通せてしまう**種類の欠陥である。

### 7.1 属性の有無で本物を判定すると取りこぼす

節 milestone を `resp="Stephanus"` で絞ると、**希 19 件・英 546 件を落とす**。
`resp` を持たない節 milestone が実在する。判定は `unit="section"` と
節 ID の形(`数字 + a–e`)で行う。

### 7.2 『書簡集』では節番号だけでは一意にならない

13 通の手紙の切れ目が**ステファヌス節の内側に落ちる**ため、同じ `310b` が
第 1 書簡の末尾と第 2 書簡の冒頭に現れる。全 7 件。
節 ID に手紙番号を含めて `Ep.2.310b` とした。

### 7.3 節境界の空白(7 件)

境界 8,559 件のうち、前後どちらにも空白が無いのは **7 件**。
最初の測定では「語中で切れる境界 161 件」と出たが、これは**測定器の欠陥**だった
(`<said>` `<p>` `<q>` の tail を拾っていなかった)。本実装と同じ走査で測り直して 7 件。
7 件はいずれも語の途中ではなく、milestone が空白の位置に立っているだけである。

### 7.4 上流の誤植 —— メノンの `ΜΕΝ.`

『メノン』で `ΜΕΝ.` が 213 件。うち 208 件は正当な `<label>`(話者 Μένων)だが、
**5 件は語中**にある。

```
ὑποπτεύοιΜΕΝ.  πέμπωΜΕΝ.  πέμποιΜΕΝ.  σκοποῦΜΕΝ.  ὡμολογήκαΜΕΝ.
```

正しくは `ὑποπτεύοιμεν` `πέμπωμεν` `πέμποιμεν` `σκοποῦμεν` `ὡμολογήκαμεν`。
話者記号の一括挿入が本文の語末を巻き込んだと見られる。

**原本は直さない。** `data/curated/corrections.json` に補正表を置き、派生データにだけ当てる。
補正は期待件数(5)を持ち、**一致しなければ例外で落ちる** —— 上流が直れば補正が落ちて気づける。
字母が誤りであることは確実だが、**挿入された可能性のあるピリオドは未確認**なので
そのまま残してある(SPEC の三区分でいう「見込み」)。

### 7.5 英訳の欠落(4 件)

英訳側に対応する節 milestone が無いものが 4 件。

| 節 | 篇 |
|---|---|
| `Symp.181b` | 饗宴 |
| `Prt.332c` | プロタゴラス |
| `HpMa.302d` | ヒッピアス(大) |
| `Ion.539d` | イオン |

英 XML を直接検索して**同名 milestone が 0 件**であることを確かめた。
英訳文そのものが失われているのではなく、**その粒度で位置指定できない**だけである。

### 7.6 『法律』743 頁の page milestone 欠落

頁の数え方が 1,752(節由来)と 1,751(`unit="page"` milestone)で 1 件ずれる。
突合したところ『法律』**743 頁に節 milestone はあるが page milestone が無い**。
節から導いた 1,752 を正とする。
