# L2 所見 — 発話交替の自前検出と較正(2026-09-02)

このループの結論をひとことで書くと、**目玉をひとつ捨て、測り直して別の形で残した**。

## 1. 何を作ったか

`etl/turns.py` —— 発話交替を**本文だけから**推定する。
校訂者の印(`said` / `label` / `sigla`)は引数にもグローバルにも現れない(G-03)。

循環の禁止は**三方向**で担保している。

| 方向 | どう確かめるか |
|---|---|
| 振る舞い | 話者記号をでたらめに差し替えても出力が 1 ビットも変わらない(T-203) |
| ソース | 検出器のコードが `sigla` / `said` / `label` を参照しない(T-203b) |
| 出荷物 | `data/turns.json` に校訂者の印を載せない(T-216) |

振る舞いの検査が主で、ソース検査は補助である。ソース検査は言及と使用を区別できず、
振る舞い検査は「たまたま影響が出なかった入力」を通すので、片方だけにしない。

## 2. 較正の相手が二系統に分かれる

これが L2 の設計上いちばん厄介だった点である。

- **上演型**は印刷面の話者記号が全交替を示すので、位置の照合ができる。
- **語り直し型**は話者記号が印刷されない。**照合の相手が存在しない。**

つまり「正解がある場所には手がかりが無く、手がかりがある場所には正解が無い」。
そこで語り直し型は、外部の正解ではなく**内部整合**で見ることにした ——
二者の問答なら、叙述内の発話動詞の人称が 1 人称(語り手)と 3 人称(相手)で交互に来るはずである。
これは校訂者の判断ではなく**文法の性質**なので循環しない。

上演型は 27 篇を交互に割り、**14 篇で閾値を決め、13 篇で報告した**。
合わせた標本で検証しても何も分からない(HC-073)。

## 3. 対照が目玉を落とした

定型応答・呼びかけ・問いの直後といった**言語的手がかりに点数を付ける**検出器を書いた。
検証側 13 篇での成績は次のとおり。

| | F1 |
|---|---|
| 手がかりの点数付け | **0.567** |
| 偶然(同数の境界を無作為に置く) | 0.043 |

偶然の 13 倍である。**対照を置かなければ、ここで「成功」と書いていた。**

置いた対照は「**文の切れ目をすべて境界とする**」という、手がかりを一切使わない素通しである。

| | F1 |
|---|---|
| 手がかりの点数付け | 0.567 |
| **文末素通し** | **0.569** |

**負けている。** 勝ったのは 13 篇中 5 篇だけだった。
偶然の 13 倍という数字は、**文の切れ目が効いているだけ**で、
定型応答も呼びかけも何ひとつ足していなかった。

境界の位置を当てるという目玉は、ここで棄却した。

## 4. 図が実際に見せるものの物差しで測り直した

画面②が読者に見せるのは「**どこで問答が濃いか**」であって、交替の厳密な位置ではない。
そこで、節ごとの交替数が正解とどれだけ揃うかで測り直した。

さらに**交絡**を潰す必要がある —— 長い節は文も交替も多いので、
「節の語数だけ」で説明できてしまうなら何も測っていない(HC-025)。

| 予測に使うもの | 節ごとの交替数との相関 |
|---|---|
| **手がかりの点数付け** | **0.756** |
| 文末素通し | 0.713 |
| 節の語数だけ | **−0.021** |

- 語数の交絡には **13/13 篇**で勝った。ステファヌス節はもともと紙面の 5 分の 1 で
  ほぼ等長なので、長さに信号が乗っていない。
- 素通しに対しては平均で上回る。**効くのは「文がすべて交替ではない篇」**である。

| 篇 | 手がかり | 素通し |
|---|---|---|
| メネクセノス | **0.850** | 0.599 |
| ラケス | **0.855** | 0.731 |
| クラテュロス | **0.810** | 0.734 |
| 法律 | **0.837** | 0.741 |
| クリティアス | **0.433** | 0.296 |
| ヒッパルコス | 0.816 | **0.893** |
| ヒッピアス(小) | 0.888 | **0.915** |

応酬が密な篇では、ほとんどの文がそのまま交替なので素通しが強い。
長い演説が混ざる篇では、手がかりが効く。**これは筋の通った分かれ方である。**

**したがって画面②が出すのは「濃さ」であって「交替の位置」ではない。**

## 5. 宣言した予測との突き合わせ

測る前に 3 つ宣言してある(`etl/calibrate_turns.py` の冒頭)。

| 予測 | 結果 |
|---|---|
| 1. 話者記号の密度が低い篇ほど外す | **成立**。密度と F1 の相関 r = 0.877。名指しした『クリティアス』『メネクセノス』は実測でも下位 1/4 |
| 2. 無作為より良い | 成立(0.567 対 0.043)。ただし §3 のとおり、これは弱い主張だった |
| 3. 語り直し型は置換対照より有意に交替する | **不成立(6/14 篇)** |

### 予測 3 が外れた理由(書き換えずに残す)

p < 0.01 になったのは 6 篇 —— 『国家』『カルミデス』『リュシス』『エウテュデモス』
『プロタゴラス』『恋がたき』。いずれも**語り手自身が対話の参加者**である篇である。

ならなかった篇には二種類ある。

- **語り手が伝聞する篇**: 『パイドン』は発話動詞 329 件のうち 1 人称がわずか 11 件
  (交替率 0.067)。パイドンがエケクラテスに語る形なので、登場人物は全員 3 人称で報告される。
  『饗宴』『パルメニデス』も同じ。**この検定は原理的に使えない。**
- **そもそも語り直し型でない篇**: 『法律』『書簡集』は人称が均衡している(1 人称 45%・53%)のに
  交替しない。発話動詞は本文中の付随的な引用で、対話の交替ではないからである。

「1 人称の割合が高ければ交替する」という後付けの規則を立てたくなるが、
**『法律』と『書簡集』が反例になる。** 規則にはせず、外れとして残す。

## 6. 副産物 —— L0 の計数を二方向で誤っていた

検出器を書く過程で、L0 の発話動詞の数え方に誤りが見つかった。

- **取りこぼし**: ギリシャ語のアクセントは後続語で鋭 → 重に変わる。
  『国家』327b の実物は `ἦ δʼ ὃς ὁ Γλαύκων` で、字面照合の `ὅς` では当たらない。
  全集で **+17**(『国家』+7・『パイドン』+6)。
- **過大計上**: 語境界を置かないと `ἔφη` が `ἔφην` の内側にも当たる。
  全集で 2,299 と数えていたが、実際は **2,028**(−271)。

両方向に誤っていたので、総数だけを見ると**それらしい数**になっていた。
『国家』の正しい内訳は 601 / 188 / 1,064 / 77 / 133 = **2,063**。
検出器で数え直した交替は **2,106**。「約 2,000 回」という主張は変わらない。

**HC-127 として起票した。** 診断は「測定そのものが妥当かを一度も試していない」で、
照合器は既知の異形と部分一致に、指標は帰無モデルと自明な代替に、それぞれ当てて確かめること。
